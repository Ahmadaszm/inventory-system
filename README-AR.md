# نظام إدارة المخزون والجرد الفعلي بالباركود QR

نظام متكامل لإدارة المخزون والجرد الدوري والمفاجئ للشركات الصناعية والاستيرادية.

## المميزات المُنفَّذة

### نموذج البيانات
- أصناف (SKU + اسم عربي/إنجليزي + تصنيف + مصدر: مصنع/استيراد)
- دفعات (Batch) منفصلة للمصنع والاستيراد
- كراتين/وحدات مخزون مع رمز QR فريد دائم
- مستودعات ومواقع (منطقة / ممر / رف / صندوق)
- أرصدة مخزون مجمّعة حسب الصنف + الدفعة + الموقع
- دفتر حركات مخزون (Ledger) كامل مع موافقات
- جلسات جرد دوري ومفاجئ (أعمى)
- سجلات العد ومنع العد المزدوج
- محرك التسوية (فروقات + قيمة مالية)
- سجل تدقيق (Audit Log)

### الواجهة (عربي RTL)
- تسجيل الدخول
- لوحة التحكم بإحصائيات حية
- قائمة الأصناف
- محطة مسح QR
- قائمة عمليات الجرد
- إنشاء جرد جديد (دوري / مفاجئ)

### الأمان
- 6 أدوار مع صلاحيات على السيرفر
- مصادقة NextAuth

## طريقة التشغيل

```bash
cd inventory-system
npm install
# انسخ .env.example إلى .env واضبط كلمة مرور قاعدة البيانات وNEXTAUTH_SECRET
cp .env.example .env
npm run db:generate
npm run db:migrate
# اختياري لقاعدة تجريبية فقط: يحذف المخزون والمستخدمين الموجودين
npm run db:seed
npm run dev
```

ثم افتح: http://localhost:3000

## الربط مع Supabase والنشر على Vercel

- يستخدم المشروع PostgreSQL عبر Prisma، وتبقى مصادقة الدخول باستخدام NextAuth.
- ضع كلمة مرور قاعدة البيانات بدل `[YOUR-PASSWORD]` في الرابطين داخل `.env`، مع ترميز الرموز الخاصة بصيغة URL.
- `DATABASE_URL` للتطبيق عبر مجمّع الاتصالات بالمنفذ `6543`، و`DIRECT_URL` للترحيلات عبر المنفذ `5432`.
- مفتاح Supabase العام لا يحل محل كلمة مرور قاعدة البيانات. متغيرا Supabase العامان متاحان لإضافات المتصفح مستقبلًا؛ استعلامات المخزون الحالية تعمل على الخادم عبر Prisma.
- في إعدادات Vercel أضف `DATABASE_URL` و`DIRECT_URL` و`NEXTAUTH_SECRET` و`NEXTAUTH_URL`، واجعل الأخير رابط الموقع المنشور بصيغة HTTPS.
- أمر البناء `npm run build` يولّد Prisma Client تلقائيًا. شغّل `npm run db:migrate` على قاعدة البيانات قبل تشغيل الموقع؛ لا تُنفّذ الترحيلات تلقائيًا مع كل بناء.
- ملف `.env` مستثنى من Git. استخدم قيمة عشوائية قوية لـ`NEXTAUTH_SECRET`.
- يفعّل الترحيل الأول RLS على جداول المخزون دون سياسات عامة، وتصل إليها اتصالات الخادم باستخدام حساب `postgres`.

## هيكل المشروع
- `prisma/schema.prisma` — نموذج البيانات الكامل
- `prisma/seed.ts` — بيانات تجريبية واقعية
- `src/lib/services/inventory.ts` — دفتر الحركات
- `src/lib/services/stocktake.ts` — محرك الجرد والتسوية
- `src/app/(dashboard)/` — الشاشات العربية

## ملاحظات
الأمر `npm run db:seed` مخصص للعرض التجريبي: يحذف البيانات الموجودة ويعيد إنشاء الحسابات التجريبية أعلاه. لا تستخدمه على قاعدة تحتوي بيانات فعلية.
